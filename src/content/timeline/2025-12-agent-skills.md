技能 = SKILL.md（模型读的说明书）+ 可选脚本（确定性代码）+ 资源文件，渐进式披露控制上下文成本。与 MCP 的分工就此清晰：MCP 给 agent 接工具（能力），skills 教 agent 做事（知识）。这是 Anthropic 继 MCP 之后第二次标准缔造尝试——skills 生态能否复制 MCP 的行业采纳速度，是 agent 工程化的关键变量。
